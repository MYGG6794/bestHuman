# bestHuman
数字人助手软件开发项目

## 项目概述
本项目是一款桌面端数字人助手软件，作为UE端数字人实时渲染的前置窗口和控制中心。具备透明抠像显示、语音交互、脚本播放、本地AI问答等核心功能。

## 核心特性
- ✅ **透明抠像显示**：WebView2接收像素流，支持绿色抠像透明背景
- ✅ **实时抠像控制**：直观参数调节界面，支持颜色、阈值、亮度等精确控制
- ✅ **桌面穿透**：点击穿透功能，数字人悬浮不影响其他应用操作
- ✅ **语音交互**：集成Windows语音识别(ASR)和语音合成(TTS)
- ✅ **脚本系统**：支持自定义讲解内容编辑和播放控制
- ✅ **本地AI**：ONNX Runtime本地AI推理，支持知识库问答
- ✅ **WebSocket通信**：与UE端实时数据交换
- 🔄 **原生透明窗口**：开发中，提供更好的桌面集成

## 使用说明

### 系统要求
- Windows 10/11 (x64)
- .NET 9.0 Runtime
- Microsoft Edge WebView2 Runtime

### 快速开始
1. **编译运行**
   ```bash
   dotnet build
   dotnet run
   ```
2. **基本操作**
   - 程序启动后会显示数字人窗口
   - 使用快捷键进行各种操作和设置

### 全局快捷键
- **Alt + S** - 打开/关闭设置窗口
- **Alt + C** - 打开/关闭抠像控制窗口
- **Alt + A** - 打开/关闭AI管理窗口
- **Alt + T** - 切换点击穿透状态

### 窗口操作功能

#### 🖱️ 窗口拖动和调整大小
在**禁用点击穿透**状态下：

**拖动窗口**
- 在窗口内容区域按住鼠标左键拖动即可移动窗口
- 窗口会自动吸附到屏幕边缘
- 释放鼠标后位置自动保存

**调整窗口大小**
- 鼠标移动到窗口边缘（8像素范围内）
- 光标变为双箭头时按住左键拖动
- 支持8个方向调整：上、下、左、右、四个角
- 最小尺寸：200x150像素
- 释放鼠标后大小自动保存

**边缘吸附功能**
- 窗口接近屏幕边缘时自动吸附
- 提供精确的边缘对齐体验

#### ⌨️ 点击穿透控制
- **Alt + T** 快捷键切换穿透状态
- **禁用穿透**：可拖动调整，正常交互
- **启用穿透**：鼠标点击穿透到桌面应用

### 抠像控制功能

#### 打开抠像控制的方式
1. **全局热键**：按 `Alt + C` （推荐）
2. **设置界面**：`Alt + S` → 点击"实时调节"按钮

#### 抠像参数说明
- **启用抠像**：总开关，控制是否启用抠像功能
- **颜色选择**：选择要抠除的背景颜色（默认绿色）
- **绿色阈值**：控制绿色分量最小值，避免浅绿误抠
- **颜色容差**：控制颜色匹配容忍度，值越大抠除范围越宽
- **最小亮度**：过暗像素不抠除，保留阴影细节
- **最大亮度**：过亮像素不抠除，避免高光溢出

#### 调节技巧
1. **先调颜色**：选择准确的背景色
2. **再调容差**：从小到大逐步调整，观察效果
3. **精调亮度**：微调亮度范围，保留边缘细节
4. **实时预览**：所有参数修改即时生效

### 语音交互功能
- **语音识别**：自动识别语音输入并传送给UE端
- **语音合成**：接收文本并播放TTS语音输出
- **实时通信**：通过WebSocket与UE端双向通信

### AI问答功能
- **本地推理**：ONNX Runtime本地AI模型
- **知识库检索**：RAG向量检索，提供准确答案
- **云端备份**：支持云API调用作为备选方案

## 详细功能说明

### 系统托盘功能
右键点击托盘图标可以快速访问：
- 显示主窗口
- 设置界面
- 抠像控制
- **切换点击穿透 (Alt+T)** 
- AI管理
- 退出程序

### 状态栏显示
窗口底部状态栏实时显示：
- 主要状态信息
- 抠像启用状态
- WebSocket连接状态
- 点击穿透状态提示

**注意**：在像素流（WebView2）模式下，状态栏会自动隐藏，避免影响底部拖动操作。

### 推荐使用流程
1. **首次启动**：程序默认禁用点击穿透，可自由拖动调整窗口
2. **调整位置大小**：拖动到合适位置，调整到合适大小
3. **设置抠像参数**：使用 Alt+C 打开抠像控制，调整抠像效果
4. **启用点击穿透**：调整完成后，使用 Alt+T 启用点击穿透
5. **日常使用**：需要调整时，再次按 Alt+T 禁用点击穿透

### 注意事项
- 启用点击穿透后，鼠标无法直接操作窗口，需要用热键或托盘菜单
- 所有窗口位置和大小变更都会自动保存到配置文件
- 状态栏会显示当前的点击穿透状态
- 托盘气泡提示会提醒您当前状态变化

## 模块化架构设计

### 1. 核心应用框架 (Core Application Framework)
**功能**：应用程序生命周期管理、主窗口创建、多线程调度、消息传递与事件处理

**核心功能点**：
- 应用程序启动与关闭逻辑
- 主事件循环管理
- 线程管理与同步机制（UI线程与后台处理线程分离）
- 系统托盘图标及菜单
- 全局热键监听

**技术实现**：C# + Windows Forms，原生Windows桌面应用框架

### 2. 数字人显示模块 (Digital Human Display Module)
**功能**：接收并渲染UE端像素流，实现抠像透明底效果，管理窗口置顶、大小和点击穿透

**核心功能点**：
- **像素流接收**：WebView2接收UE Pixel Streaming
- **实时渲染**：高效像素数据实时渲染
- **抠像处理**：
  - 支持自定义抠像背景颜色（RGB/HSV）
  - 颜色容差设置，优化抠像效果
  - 基于颜色键（Chroma Key）的透明化处理
  - 亮度范围控制，保护阴影和高光细节
- **窗口管理**：
  - 窗口置顶显示
  - 点击穿透功能
  - 窗口拖动和大小调整
  - 边缘吸附功能
  - 无边框自定义外观

**技术实现**：WebView2 + JavaScript像素处理 + Windows API

### 3. 后台管理界面模块 (Backend Management UI Module)
**功能**：图形用户界面，配置和管理软件功能参数，支持快捷键控制

**核心功能点**：
- **界面设计**：简洁直观的操作界面
- **快捷键管理**：全局热键监听和响应
- **配置项管理**：
  - 数字人推流地址配置
  - 抠像颜色和参数设置
  - 窗口尺寸位置配置
  - 语音识别/合成参数
  - AI模型和知识库路径
  - 点击穿透开关
- **配置持久化**：JSON格式配置文件自动保存加载
- **状态显示**：实时显示各模块连接和运行状态

**技术实现**：Windows Forms + System.Configuration + JSON序列化

### 4. 语音服务模块 (Speech Services Module)
**功能**：集成Windows语音识别（ASR）和语音合成（TTS），通过WebSocket与UE端通信

**核心功能点**：
- **语音识别 (ASR)**：
  - Windows Speech Recognition API
  - 支持多语言识别模型
  - 实时识别结果WebSocket推送
- **语音合成 (TTS)**：
  - Windows SAPI语音合成
  - 多音色选择，语速音量调节
  - 接收UE端文本并播放合成语音
- **WebSocket接口**：
  - ASR文本推送协议
  - TTS文本接收协议
  - 播放状态通知协议

**技术实现**：System.Speech + WebSocket通信

### 5. 讲解词与动作脚本模块 (Scripting & Action Script Module)
**功能**：自定义讲解词内容和数字人动作序列，通过WebSocket驱动UE端执行

**核心功能点**：
- **脚本管理**：
  - 创建、编辑、保存、加载脚本
  - 文本编辑器支持
  - 结构化动作序列编辑
- **脚本格式**：JSON结构化格式
  - 脚本ID和标题
  - 分段讲解内容
  - 对应动作序列
  - 语音参数设置
- **播放控制**：
  - 播放、暂停、停止、循环
  - 进度显示和跳转
  - 语音与动作同步

**技术实现**：JSON序列化 + Windows Forms UI + WebSocket协议

### 6. 本地AI与知识库模块 (Local AI & Knowledge Base Module)
**功能**：内嵌AI模型实现语义理解，支持知识库检索增强生成（RAG）

**核心功能点**：
- **AI模型集成**：
  - ONNX Runtime推理引擎
  - 支持多种AI模型格式
  - CPU/GPU推理优化
  - 模型量化支持
- **知识库管理**：
  - 多格式知识库支持（JSON、Markdown、文本）
  - 向量检索系统
  - RAG检索增强生成
- **语义理解与生成**：
  - 用户问题理解
  - 知识库上下文检索
  - 准确回复生成
  - 云端API备选方案

**技术实现**：ONNX Runtime + 向量检索 + WebSocket通信

### 7. 网络通信模块 (Network Communication Module)
**功能**：统一管理与UE端WebSocket通信，包括连接管理、消息发送接收、协议解析

**核心功能点**：
- **WebSocket客户端**：连接UE端Pixel Streaming服务
- **连接管理**：连接、断开、重连机制
- **消息处理**：
  - 发送：ASR文本、TTS状态、脚本指令、AI回答
  - 接收：TTS文本、用户操作、AI请求
- **协议解析**：JSON格式消息协议，类型化数据结构
- **错误处理**：连接失败、消息发送失败等异常处理

**技术实现**：System.Net.WebSockets + JSON序列化

### 8. 通用工具与服务模块 (Utilities & Common Services Module)
**功能**：提供应用程序通用辅助功能

**核心功能点**：
- **日志系统**：多级别日志输出，文件和控制台输出
- **配置管理**：统一配置读写接口，多格式支持
- **数据校验**：输入参数合法性验证
- **辅助函数**：字符串处理、文件操作、时间处理等

**技术实现**：.NET内置日志 + 文件IO + 数据验证
